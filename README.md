# Snake на Go

Небольшая пошаговая консольная «Змейка» для тестирования репозитория.
Только стандартная библиотека, без внешних зависимостей. Требуется Go 1.22 или новее.

## Запуск

```sh
go run .
```

Введите `W`, `A`, `S` или `D` и нажмите Enter, чтобы сделать ход.
Пустой ввод продолжает движение, `Q` завершает игру. Регистр не важен.
Неизвестная команда не делает ход; разворот на 180° игнорируется, змейка движется вперёд.

`@` — голова, `o` — тело, `*` — еда. Каждая съеденная еда добавляет
одно очко и одну клетку длины. Столкновение со стеной или телом завершает игру;
заполнение всего поля означает победу.

## Проверки

```sh
go test -race ./...
go vet ./...
go build -o snake .
```

Тесты проверяют движение, рост, столкновения, запрет разворота,
переход в освобождаемую клетку хвоста, размещение еды и победу.
GitHub Actions запускает тесты, vet и сборку при push и pull request.
